# CodeKids Keyboard Academy（键盘小侠）

面向 6-10 岁儿童的键盘盲打 + 编程启蒙网页应用。当前为 **MVP 第一阶段**。

## 已实现

- 首页（产品介绍与入口）
- 儿童登录（头像选择 + 图形密码）
- 学习地图（5 个阶段，阶段 1 可玩）
- 打字训练页（目标字符、虚拟键盘、手指提示、实时 WPM/正确率、错误分析、结语结算）

## 常用命令

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm run build      # 生产构建
npm run typecheck  # 类型检查
```
