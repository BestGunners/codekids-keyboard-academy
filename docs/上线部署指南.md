# CodeKids Keyboard Academy 上线部署指南

## 0. 先搞清楚这个项目需要什么

- 它是**纯前端**项目（React + Vite），没有后端、没有数据库。
- 孩子的档案、关卡进度、星星徽章、设置都存在**浏览器本地**（localStorage，键名 `codekids.child` / `codekids.progress` / `codekids.settings`）。
- 所以"上线" = 把 `npm run build` 生成的 `dist` 文件夹放到一个静态网站托管上，不需要买服务器、不需要数据库。

两个必须注意的点：

1. **前端路由需要 SPA 回退**：网址直接访问 `/map`、`/lesson/s1-l01` 时，服务器要把请求交给 `index.html`，否则刷新就 404。项目里已经准备好了 `vercel.json`、`netlify.toml`、`public/_redirects` 三份配置。
2. **进度只存在当前这台设备的当前浏览器里**：换电脑、换浏览器、清缓存都会看不到。要做到手机电脑同步、家长远程看进度，需要以后加后端（见第 7 节）。

## 2. 三种上线方式（按省事程度排）

### 方式 A：Vercel（推荐，免费、自动 HTTPS、自带全球 CDN）

1. 先把代码放到 GitHub（新建一个仓库，把项目推上去）。
2. 打开 [vercel.com](https://vercel.com)，用 GitHub 账号登录 → **Add New → Project** → 选中这个仓库。
3. Framework 会自动识别成 **Vite**；确认 Build Command 是 `npm run build`、Output Directory 是 `dist` → 点 **Deploy**。
4. 约 1 分钟后拿到 `https://xxx.vercel.app` 网址；以后每次 `git push` 都会自动重新部署。

不想连 GitHub 也可以：在项目目录执行 `npx vercel`，按提示回车，最后 `npx vercel --prod` 正式发布。

### 方式 B：Netlify（"拖一下"最快）

- **临时分享**：`npm.cmd run build` 之后，把 `dist` 文件夹整个拖到 [app.netlify.com/drop](https://app.netlify.com/drop)，几秒后就有网址（登录后可以保留站点）。
- **正式部署**：连接 GitHub 仓库，Netlify 会自动读取项目里的 `netlify.toml`（构建命令 + 路由回退都写好了）。

### 方式 C：Cloudflare Pages（国内访问相对稳一些）

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Pages → 连接 GitHub**。
2. Build command 填 `npm run build`，Build output directory 填 `dist`。
3. `public/_redirects` 会被自动识别，路由回退不用额外设置。

## 3. 用自己的域名 / 国内加速

- **域名**：在腾讯云、阿里云买一个（`.com` 约 60–80 元/年），在 DNS 里加一条 CNAME 指向平台给的地址即可，HTTPS 证书平台会自动签。
- **腾讯云 COS / 阿里云 OSS**：把 `dist` 整个上传到存储桶 → 开启「静态网站」→ 绑定自定义域名 + CDN + 证书。注意域名指向国内服务器/CDN 需要**备案**。
- **自己的服务器 + Nginx**（`root` 指向上传上去的 `dist`）：

```nginx
server {
  listen 80;
  server_name 你的域名;
  root /var/www/codekids/dist;
  index index.html;

  # 前端路由回退：刷新 /map、/lesson/xxx 不会 404
  location / {
    try_files $uri $uri/ /index.html;
  }

  # 带 hash 的静态资源可以放心长缓存
  location /assets/ {
    expires 30d;
    add_header Cache-Control "public, immutable";
  }
}
```

证书可以用 `certbot --nginx` 免费申请 Let's Encrypt HTTPS。

## 4. 只想先给身边的人看看（5 分钟）

- **同一个 WiFi**：`npm.cmd run preview -- --host`，把终端里显示的 `http://192.168.x.x:4173` 发给对方（手机也能打开看界面，但要打字得配外接键盘）。
- **公网临时**：把 `dist` 拖到 Netlify Drop，或者 `npx vercel --prod`。

## 6. 如果部署在子路径（GitHub Pages 这类）

只有当网址长这样时才需要处理：`https://用户名.github.io/仓库名/`

- 在 `vite.config.ts` 里加一行 `base: '/仓库名/'`
- 并把 `src/styles/kid.css` 里 `/fonts/zcool-kuaile.woff2` 改成走 `import.meta.env.BASE_URL`
- GitHub Pages 还要把 `dist/index.html` 复制一份成 `dist/404.html` 做回退

用 Vercel / Netlify / Cloudflare Pages 或自己的域名（部署在根目录）**不需要**这些改动。

## 7. 以后想继续做的

- **多设备同步、家长端远程看进度**：需要加后端（Supabase、微信云开发、或自建 Node + 数据库都行）。前端只需要替换 store 里的持久化层，`src/store/childStore.ts` 里已经写了注释留好位置。
- **像 App 一样装到桌面、离线也能玩**：加 `vite-plugin-pwa`（本项目字体和音效都自托管，本来就没有外部依赖，很适合做离线）。
- **看有多少人在玩**：加 Vercel Analytics、Cloudflare Web Analytics 或百度统计，一行代码。
